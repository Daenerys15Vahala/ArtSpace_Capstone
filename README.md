# ArtSpace - Capstone Project

ArtSpace is a full-stack web application designed for artists to showcase their artwork and for users to discover, browse, and save artwork for inspiration.

## Project Goals

- Allow artists to upload and manage artwork
- Allow users to browse artwork by category
- Allow users to save favorite artwork
- Provide a secure and organized platform for discovering art

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL
- React
- JavaScript
- HTML/CSS
- Git/GitHub
